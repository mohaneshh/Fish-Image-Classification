# Fish Image Classification 🐟

A deep learning project for classifying different species of fish using Convolutional Neural Networks (CNNs) on a large-scale fish dataset.

## 📌 Overview

This project demonstrates how to build and train a CNN model for multi-class image classification of fish species. It includes data preprocessing, model building, training, evaluation, and prediction.

## 🐟 Dataset

The dataset used is the [Large-Scale Fish Dataset](https://www.kaggle.com/datasets/crowww/a-large-scale-fish-dataset) from Kaggle.  
It contains over 4,000 high-resolution images of fish belonging to **9 species**, organized into class-wise folders:

- Black Sea Sprat
- Gilt-Head Bream
- Hourse Mackerel
- Red Mullet
- Red Sea Bream
- Sea Bass
- Shrimp
- Striped Red Mullet
- Trout

> **Note**: Due to size constraints, the dataset is not included in this repository. Please download it directly from Kaggle and place it in the appropriate directory.

## 🧠 Techniques Used

- Convolutional Neural Networks (CNN)
- Image preprocessing and augmentation
- Keras `ImageDataGenerator`
- Train/validation split and model evaluation
- Accuracy, loss, and prediction visualization
